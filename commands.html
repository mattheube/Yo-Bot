Toutes les commandes Yo-Bot

Les commandes publiques, celles réservées aux administrateurs de serveur et les outils internes des développeurs sont séparés clairement.

PublicTous les joueurs AdminPermission Administrateur Discord DevID autorisé dans le code du bot

Le nom de Bingo-Kai est le seul nom de commande actuellement localisé dans le code. Les autres noms restent identiques.

Essentiel Collection Combats Interactions Admin serveur Développeurs
01

Pour commencer

Essentiel

Aide, profil, progression et découverte du catalogue.

/helpPublic

Ouvre le panneau d’aide interactif dans la langue du serveur.

/profile (user)Public

Affiche ton profil Yo-Bot ou celui du joueur choisi.

/trophiesPublic

Affiche les succès et permet d’équiper un titre débloqué.

/viewPublic

Parcourt les objets, nourritures, accessoires et pièces utilisables.

02

Ton aventure

Collection & économie

Équipes, Medallium, inventaire, Bingo-Kai et boutique.

/team (user) (kind)Public

Ouvre le panneau d’équipe ou consulte celle d’un autre joueur.

/medallium (user) (universe)Public

Parcourt le Medallium d’un joueur dans tous les univers ou un jeu précis.

/invocation yokai (user)Public

Affiche la fiche d’un Yo-kai et le nombre d’exemplaires possédés.

/inventory (user)Public

Affiche les pièces, objets, nourritures et accessoires.

/bingo-kaiPublic

Ouvre le panneau de tirage Bingo-Kai. Son nom s’adapte à la langue Discord sélectionnée.

/bkaiPublic

Alias court qui ouvre le même panneau de tirage.

/buy item (quantity)Public

Achète un objet disponible dans la boutique actuelle.

/sellPublic

Ouvre le panneau privé de revente des ressources.

03

À l’action

Rencontres & combats

Yo-kai sauvages, amitié, Boss Drops et matchmaking PvP.

/yokai (universe)Public

Cherche un Yo-kai sauvage dans l’univers choisi.

/befriend namePublic

Tente de devenir ami avec le Yo-kai sauvage actif dans le salon.

/boss-drop yokaiPublic

Montre les récompenses d’amitié disponibles pour un boss.

/pvp friendly (opponent)Public

Défie un joueur ou rejoint le matchmaking amical.

/pvp bet amount (opponent)Public

Lance un défi ou un matchmaking avec une mise.

/pvp rankedPublic

Rejoint la file de matchmaking classée.

/pvp pausePublic

Met temporairement la recherche PvP en pause.

/pvp resumePublic

Reprend une recherche PvP mise en pause.

/pvp cancelPublic

Quitte proprement la file de matchmaking.

04

Jouer ensemble

Interactions

Guildes, échanges, drops et partie Undercover.

/guild (member)Public

Crée, rejoint, consulte et gère une guilde globale.

/trade userPublic

Invite un joueur dans un échange privé de Yo-kai.

/drop kind reward quantity claimantsPublic

Propose publiquement une ressource de ton inventaire.

/undercover mode joueurs (agents) inconnus (acces) (theme) inconnu_commence rapidePublic

Organise une partie Undercover vocale ou textuelle.

05

Permission Discord

Administration du serveur

Ces commandes exigent la permission Administrateur sur le serveur où elles sont utilisées.

/setupAdmin

Ouvre le panneau des setups : apparitions, raids, Help, Shop, salons et restrictions.

/resetAdmin

Ouvre le panneau de réinitialisation des configurations existantes.

/notificationAdmin

Configure les rôles de notification globaux ou par rang.

/language languageAdmin

Définit la langue de Yo-Bot pour le serveur.

Dev
Outils internes de Yo-Bot

Ces commandes ne dépendent pas de la permission Administrateur Discord. Elles vérifient que l’ID de l’utilisateur figure dans BOT_ADMIN_IDS dans le code du bot.

06

Accès restreint par ID

Développeurs du bot

Forçage d’événements, maintenance, modération interne et gestion d’inventaire.

/giveDev

Ouvre le panneau privé permettant de donner des ressources à un joueur.

/removeDev

Ouvre le panneau privé permettant de retirer des ressources à un joueur.

/cooldown action user (seconds) (uses)Dev

Modifie ou réinitialise le cooldown de la commande /yokai pour un utilisateur.

/spawn yokai yokai (quantite)Dev

Force une apparition sauvage dans le salon actuel.

/spawn raid-yokai yokai (niveau)Dev

Force un Yo-kai Raid normal dans le salon actuel.

/spawn boss-raid yokai (niveau)Dev

Force un Boss Raid dans le salon actuel.

/update-helpDev

Actualise l’aide publique dans tous les serveurs configurés.

/owner ban user (duration_minutes) (reason)Dev

Bannit un utilisateur de Yo-Bot temporairement ou définitivement.

/owner unban userDev

Retire le bannissement interne d’un utilisateur.

/owner servers (page)Dev

Affiche les serveurs utilisant actuellement Yo-Bot.

Aucune commande ne correspond à cette recherche.
