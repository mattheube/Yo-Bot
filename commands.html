Guide de jeu

Commandes Yo-Bot

Les commandes utiles sont courtes; les choix détaillés se font ensuite dans les embeds, menus et formulaires Discord.

Essentiel Collection Combats Jeux de groupe Configuration

01

Essentiel

Commencer, consulter sa progression et choisir la langue du serveur.

/help

Ouvre le panneau d'aide interactif dans la langue du serveur.

/profile

Affiche le niveau, l'argent, l'ELO et les statistiques PvE et PvP.

/language

Choisit le français ou l'anglais pour Yo-Bot sur le serveur.

02

Collection et économie

Gérer les Yo-kai, les équipes, les objets, les pièces et les échanges.

/team

Configure les équipes PvE, PvP et raid de six Yo-kai depuis un panneau.

/medallium

Parcourt le Medallium d'un joueur par tribu et par pages.

/invocation

Présente un Yo-kai et indique le nombre d'exemplaires possédés.

/inventory

Affiche les pièces, nourritures, objets, accessoires et ressources.

/view

Explore le catalogue illustré des éléments réellement utilisables par le bot.

/bingo-kai

Ouvre le Bingo-Kai privé, choisit une pièce et confirme jusqu'à dix tirages.

/bkai

Alias court de /bingo-kai, sans option supplémentaire.

/buy

Achète un objet de la boutique automatique après confirmation.

/sell

Ouvre le panneau privé pour revendre des ressources de l'inventaire.

/drop

Propose publiquement une ressource issue de son propre inventaire.

/trade

Lance un échange sécurisé de Yo-kai entre deux joueurs.

03

Combats

Rencontres sauvages, amitié, PvE, informations de raid et matchmaking PvP.

/yokai

Cherche une rencontre sauvage et permet d'accepter ou d'éviter le combat.

/befriend

Tente de devenir ami avec le Yo-kai sauvage classique actif dans le salon.

/battle

Lance un combat PvE rapide avec l'équipe PvE actuelle.

/boss-drop

Montre les Yo-kai pouvant être obtenus grâce à un boss.

/pvp friendly

Défie un joueur ou cherche un adversaire pour un match amical.

/pvp bet

Lance un défi ou un matchmaking avec une mise d'argent.

/pvp ranked

Entre dans la file classée avec recherche par proximité d'ELO.

/pvp pause

Met temporairement la recherche PvP en pause.

/pvp resume

Relance une recherche PvP mise en pause.

/pvp cancel

Quitte proprement la file de matchmaking.

04

Jeux de groupe

Des activités conçues pour jouer ensemble sur un serveur.

/undercover

Crée une partie vocale ou textuelle avec lobby, mots secrets et votes anonymes.

05

Configuration serveur

Ces commandes demandent les permissions d'administration du serveur.

/setup yokai-spawn Admin

Configure un ou deux salons d'apparitions sauvages classiques.

/setup mystery-yokai-spawn Admin

Configure l'unique salon des Yo-kai mystérieux.

/setup yokai-raid Admin

Configure l'unique salon de raids Yo-kai adaptés aux joueurs.

/setup boss-raid Admin

Configure l'unique salon de boss raids de niveau 99.

/setup shop Admin

Configure la boutique automatique et son rôle de notification optionnel.

/setup help Admin

Publie le guide public dans un unique salon et mémorise son rôle de mise à jour.

/setup create-defaults Admin

Crée les salons par défaut manquants sans dupliquer les configurations.

/setup reset Admin

Retire une configuration de spawn, de raid ou de boutique.

/setup lock-command Admin

Limite une commande à un ou deux salons déterminés.

/setup unlock-command Admin

Retire une restriction de salon appliquée à une commande.

/setup notification-role Admin

Sélectionne un rôle existant ou crée un rôle avec le nom choisi.

/setup reset-notification-role Admin

Retire un rôle de notification configuré.

/setup create-notification-roles Admin

Crée les rôles de notification standards avec des noms personnalisés.

/protect-serveur Admin

Ouvre les outils de sauvegarde et de protection de structure du serveur.
